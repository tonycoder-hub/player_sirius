# Player Sirius 回归清单

## 基础播放

- 本地视频导入后可以正常打开、播放、暂停、停止、重播
- 网络 `http/https` 直链可以正常播放
- `m3u8` HLS 可以打开并显示可用码率档位
- 横竖屏切换、画面缩放、旋转在播放中可用

## 字幕与音轨

- 选择 `.srt` 外挂字幕后可以正常渲染
- 字幕开关可用，关闭后画面不再显示字幕
- 字幕偏移正负调整后，时间轴同步变化
- 多音轨资源在 `AVPlayer` 内核下可枚举并切换

## 失败回退

- 自动策略下，本地媒体默认走 `ArkUI Video`
- 自动策略下，网络流默认走 `AVPlayer`
- 当前内核打开失败后，能自动回退到另一条内核路径一次
- 回退结果会在 UI 中显示

## 后台与焦点

- 播放中退到后台后不断播
- 锁屏后保持播放
- 来电/其他音频应用抢占时触发暂停
- 抢占结束后触发恢复或恢复音量

## 缓冲与弱网

- 首帧耗时可以显示
- 缓冲百分比和缓存时长可以显示
- 弱网卡顿时出现提示
- 网络异常时会自动重试，且有次数上限

## 远端协议栈

- WebDAV 可列目录
- WebDAV 鉴权下载到缓存后可播放
- FTP 可列目录
- FTP 下载到缓存后可播放

## 投屏

- SSDP 可以发现局域网 DLNA 设备
- 可以选择设备并投送当前 `http/https` 媒体
- `Play/Pause/Stop` 控制可下发

## 媒体库

- 批量导入视频后可出现在媒体库
- 支持文件夹筛选
- 本地视频会生成首帧缩略图缓存
- 媒体信息面板可显示基础元数据

## 亮度与手势

- 左侧竖滑调亮度
- 右侧竖滑调音量
- 横向滑动调进度
- 页面退出后窗口亮度恢复跟随系统
